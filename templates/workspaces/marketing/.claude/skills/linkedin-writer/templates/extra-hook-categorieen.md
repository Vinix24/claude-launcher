# Extra hook-categorieën

Uitgebreide voorbeelden voor de drie hook-categorieën K, L, M uit `SKILL.md`. Vervang de generieke voorbeelden door eigen content uit jouw `brand-voice.md`.

---

## K. Behind-the-scenes / Insider hook

Laat de lezer achter het gordijn kijken. Werkt omdat het exclusiviteit en transparantie combineert.

**Formule:**

```
"Dit is wat er echt gebeurt als [proces/systeem/situatie]."
"Achter de schermen van [specifiek systeem]: [onverwacht detail]."
```

**Voorbeelden:**

```
Dit is wat er echt gebeurt als meerdere AI-agents tegelijk draaien.
```

```
Achter de schermen van mijn dispatch queue: tientallen beslissingen per minuut.
```

```
Dit ziet niemand: wat er gebeurt als een AI-agent faalt in productie.
```

**Best voor:** Architecture deep dives, proof of work, build logs
**Werkt omdat:** Mensen willen insider-kennis. "Achter de schermen" triggert curiosity gap + exclusiviteit.

---

## L. Transformation Timeline hook

Laat een voor/na zien met een tijdlijn. Sterker dan een los getal omdat het de reis laat zien.

**Formule:**

```
"[Tijdstip]: [oude situatie]. Nu: [nieuwe realiteit]."
"[Periode] geleden [startpunt]. Vandaag: [resultaat]."
```

**Voorbeelden:**

```
6 maanden geleden: 0 klanten, 0 bewijs. Nu: een werkend systeem en concrete resultaten.
```

```
Januari: een idee op een whiteboard. Maart: een productiesysteem.
```

```
Vorig jaar schreef ik rapporten. Nu bouw ik systemen. Het verschil is alles.
```

**Best voor:** Proof of work, milestone posts
**Werkt omdat:** Tijdlijnen maken resultaten geloofwaardig (het is een reis, geen claim) en triggeren "hoe heeft hij dat gedaan?"

---

## M. Myth vs. Truth hook

Stel een gangbare mythe tegenover de realiteit. Scherper dan een contrarian take omdat het de lezer expliciet een nieuw mentaal model geeft.

**Formule:**

```
"Mythe: [gangbare aanname]. Realiteit: [wat jij weet uit ervaring]."
"Iedereen denkt [X]. De data zegt [Y]."
```

**Voorbeelden:**

```
Mythe: AI vervangt je team. Realiteit: AI zonder architectuur verdubbelt je chaos.
```

```
Mythe: je hebt een AI-strategie nodig. Realiteit: je hebt een architect nodig.
```

```
Mythe: open source betekent gratis weggeven. Realiteit: open source is de sterkste sales funnel die er is.
```

**Best voor:** Contrarian content, thought leadership, productpositionering
**Werkt omdat:** Het "Mythe/Realiteit" format is direct herkenbaar, creëert cognitieve dissonantie, en positioneert de auteur als insider die de waarheid kent.

---

## Hook-selectie per topic-cluster

| Pillar / topic | Extra hooks | Waarom |
|---|---|---|
| Strategie / advies | M (myth vs truth), L (timeline) | Beslissers geloven mythen en reageren op transformaties |
| Build logs / productie | K (behind-the-scenes), L (timeline) | Tech-geïnteresseerden willen insider-kennis en bouwverhalen |
| Tactiek / how-to | M (myth vs truth) | Mythes zijn een perfect ingang voor concrete adviezen |
