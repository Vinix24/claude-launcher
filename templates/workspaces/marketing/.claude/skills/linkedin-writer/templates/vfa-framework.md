# VFA Framework — Emotionele Posts

**Bron:** Justin Welsh (9K+ engagements, 3K nieuwe volgers, 2.3K email subs op één post)
**Gebruik:** Persoonlijke, emotionele posts met een sterke overtuiging.
**Sterkste voor:** Open source beslissingen, persoonlijke identiteit, "waarom ik dit doe" posts.

## De 3 stappen

### V: Visceral Opener — Raak ze in de maag

Begin met dramatische, emotioneel geladen taal. Geen abstractie — een concreet beeld.

```
Ik stopte met adviseren en begon te bouwen.
```

```
6 maanden geleden had ik geen klanten, geen product, geen bewijs.
```

```
Ik zette mijn complete architectuur open source. Alles. Elke regel code.
```

### F: Fresh Perspective — Draai de verwachting om

Introduceer een onverwacht of tegendraads standpunt. De lezer dacht dat het verhaal
één kant op ging — nu gaat het de andere kant op.

```
Niet omdat ik altruïstisch ben.
Maar omdat transparantie de beste salesmachine is die er bestaat.
```

```
Geen AI-strategie. Geen roadmap. Geen PowerPoint.
Gewoon een werkend systeem en de wil om het te delen.
```

### A: Anaphora — Herhaal voor impact

Gebruik herhaalde zinsstructuur om je kernboodschap in te hameren.
Elke herhaling is een jab — samen worden ze een knock-out.

```
Ik bouw geen rapporten. Ik bouw systemen.
Ik verkoop geen uren. Ik lever architectuur.
Ik verstop geen code. Ik zet het op GitHub.
Ik beloof geen resultaten. Ik laat ze zien.
```

```
Geen NDA's die mijn werk verbergen.
Geen black-box die niemand begrijpt.
Geen afhankelijkheid die je niet kunt doorbreken.
```

## Compleet voorbeeld

```
Ik zette mijn complete architectuur open source. Alles.

Niet omdat ik naïef ben.
Maar omdat ik geloof dat de beste manier om te bewijzen
wat je kunt, is door het te laten zien.

Geen NDA's die mijn werk verbergen.
Geen black-box die niemand begrijpt.
Geen "vertrouw ons" zonder bewijs.
Geen rapport dat in een la verdwijnt.

Een open systeem. Alles inzichtelijk. Alles reproduceerbaar.

De reactie die ik het vaakst krijg:
"Als dit is wat je gratis weggeeft, wat kun je dan voor geld?"

Precies.

———
Voeg een korte CTA toe die past bij jouw aanbod (uit brand-voice.md).
```

## Wanneer VFA gebruiken

- Persoonlijke overtuiging of filosofie posts
- "Waarom open source" / "waarom ik dit doe" posts
- Identiteit-posts: wat maakt jou anders dan de concurrentie

## Wanneer NIET gebruiken

- Technische deep dives, te emotioneel
- Listicles of how-to content, anaphora past niet bij stappen
- Product-promotie posts, PAIPS werkt beter

## Anaphora voorbeelden

**Open source / transparantie:**
```
Ik deel mijn proces. Ik deel mijn fouten.
Ik deel mijn metingen. Ik deel mijn beslissingen.
```

**Anti-consultant:**
```
Geen rapport van 40 pagina's. Geen "fase 2 offerte".
Geen maandelijks "alignment meeting". Geen vendor lock-in.
```

**Maker-identiteit:**
```
Ik ontwerp. Ik bouw. Ik documenteer. Ik draag over.
```
